使用帮助

正向转换（XMind → 其他格式）

  1. 点击"XMind → 其他格式"标签
  2. 上传 .xmind 文件
  3. 选择要导出的 Sheet
  4. 选择导出格式（Markdown、Word、大纲）
  5. 点击"开始转换"
  6. 下载转换后的文件

反向转换（其他格式 → XMind）

  1. 点击"其他格式 → XMind"标签
  2. 上传 .md、.docx 或 .txt 文件
  3. 选择源格式
  4. 点击"反向转换"
  5. 下载生成的 .xmind 文件

配置管理

  • 点击右上角"设置"按钮
  • 设置临时文件保留策略
  • 设置自动清理规则
  • 配置自动保存到 config.json

临时文件管理

  • 点击右上角"临时文件"按钮
  • 查看临时文件列表和大小
  • 手动清理过期或所有文件

格式说明

源格式 转换规则
Markdown # 标题 → 一级节点，## 标题 → 二级节点
Word Heading 1 → 一级节点，Heading 2 → 二级节点
大纲 缩进级别 → 父子关系，项目符号 → 节点标记
